Video.js CMCD v2 Plugin Example

🚀 CMCD v2 Features Demonstrated:

  • Response Mode: Collects metrics after HTTP responses (TTFB, TTLB, Response Code, etc.)
  • Event Mode: Reports on player events (play, pause, error, etc.)
  • Multiple Transmission Modes: JSON batch, Query parameters, HTTP headers
  • Flexible Targeting: Multiple endpoints with different configurations

CMCD v2 Configuration Used:

var player = videojs('my-video');

player.cmcd({
    version: 2,
    sid: 'session-12345',
    cid: 'content-67890',
    targets: [
        // Response Mode - JSON Batch
        {
            mode: 'response',
            url: 'http://localhost:3001/cmcd/response',
            transmissionMode: 'json',
            batchSize: 3,
            enabledKeys: ['ts', 'ttfb', 'ttlb', 'rc', 'url', 'pt'],
            includeOnRequests: ['segment', 'manifest']
        },

        // Event Mode - Query String
        {
            mode: 'event',
            url: 'http://localhost:3002/cmcd/event',
            transmissionMode: 'query',
            timeInterval: 5, // seconds
            enabledKeys: ['ts', 'e', 'sta', 'pt', 'pr'],
            events: ['ps', 'e', 't'] // playback state, error, time
        },

        // Event Mode - HTTP Headers
        {
            mode: 'event',
            url: 'http://localhost:3003/cmcd/event-headers',
            transmissionMode: 'header',
            enabledKeys: ['ts', 'e', 'sta', 'msd', 'df'],
            events: ['ps', 'e']
        }
    ]
});

📊 What's Being Reported:

  • Response Mode: Network timing data for each segment/manifest request
  • Event Mode (Query): Player state changes every 5 seconds + events
  • Event Mode (Headers): Critical events like play/pause/error

Note: Make sure your CMCD collection endpoints are running on the specified ports to see the data flow.
